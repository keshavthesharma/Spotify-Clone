#Spotify Website Clone

A static, multi-page clone of the Spotify web interface. This project demonstrates fundamental web development skills and UI design principles without the use of JavaScript or external CSS frameworks[cite: 1].

## Features
* **Multi-Page Navigation:** Includes a Home page, Browse page, Playlist Details page, and a Login page linked together using standard anchor tags[cite: 1].
* **Modern Layouts:** Utilizes CSS Flexbox for structuring the navigation bar and arranging the responsive playlist and genre cards[cite: 1].
* **Semantic HTML:** Built with proper HTML5 structural tags including `<header>`, `<nav>`, `<main>`, and `<footer>`[cite: 1].
* **Spotify Branding:** Implements the required Spotify color palette, specifically Green `#1DB954` and Black `#191414`[cite: 1].
* **User Input UI:** Features a styled login page to demonstrate the use of `<form>` and `<input>` elements[cite: 1].
* **Hover Effects:** Includes interactive CSS hover states on navigation links and buttons for a better user experience[cite: 1].

## Tech Stack
* HTML5[cite: 1]
* CSS3 (Flexbox, Box Model, Selectors)[cite: 1]
